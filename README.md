# Корпоративная информационная система. Конфигурация для 1С:Предприятие "Волна Университет"

Мечта автора - устроиться работать в музыкальный лейбл Волна программистом, стать его сотрудником.

Эта конфигурация - прототип КИС для музыкального лейбла на 1С (как 1С:Театр, но не театр, а лейбл, дистрибутор или студия).
